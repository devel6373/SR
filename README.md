# Shadowrocket: дом + улица

- **Wi‑Fi** → заблокированное через свой сервер zayavkin.store (Hysteria2 + VLESS‑Reality, автовыбор), российское и Apple — напрямую (`Rocket-WiFi.conf`).
- **Сотовая** → белосписочные узлы Geodema из рабочего пула, живой выбирается автоматически (`Rocket-Cellular.conf`).
- Между ними приложение переключается само, через **сцены**.

Ссылки на конфиги:
```
https://cdn.jsdelivr.net/gh/devel6373/SR@main/Rocket-WiFi.conf
https://cdn.jsdelivr.net/gh/devel6373/SR@main/Rocket-Cellular.conf
```
jsDelivr кэширует файлы до 12 часов. После заливки новой версии на GitHub сбросьте кэш, открыв
`https://purge.jsdelivr.net/gh/devel6373/SR@main/Rocket-WiFi.conf` (и то же для `Rocket-Cellular.conf`).

## Настройка

1. **Свой сервер.** Главная → **«+»** → вставьте ссылки `hysteria2://…` и `vless://…`. Имена строго **«🇩🇪 Германия Hysteria…»** и **«🇩🇪 Германия Vless»**: группа VPN Wi‑Fi‑конфига находит их по `Германия Hysteria` / `Германия Vless`.
2. **Подписка WL.** Главная → **«+»** → «Подписка» → ваша ссылка Geodema White-List. В её настройках: **User-Agent → `ClashMeta`** → «Обновить». Должно появиться около 54 узлов.
3. **Конфиги.** Вкладка «Конфиг» → **«+»** → добавьте обе ссылки выше.
4. **Группы.** Выбирать ничего не нужно — все группы с автовыбором. Проверьте состав: Wi‑Fi VPN — 2 узла; сотовая VPN — 10, RU-SILVER — 1, RU-COOPER — 1, RU — цепочка (Silver → Cooper → VPN).
5. **Туннель.** Настройки → Туннель: **«Включить все сети»** и **«Включить APNs»** → вкл.
6. **По требованию.** Настройки → «По требованию»:
   - переключатель «По требованию» → **вкл**;
   - «Всегда включён» → **выкл**;
   - «Отключаться во сне» → **выкл**;
   - правило оставьте одно: **«Подключаться · Любой»**, остальные удалите.
7. **GeoIP (необязательно).** Настройки → «База GeoLite2» (GeoLite2 Database):
   - нажмите **Country** → вставьте `https://cdn.jsdelivr.net/gh/Loyalsoldier/geoip@release/Country-without-asn.mmdb` → сохраните;
   - нажмите **«Обновить»** и дождитесь, пока сменится дата базы. Делайте это дома с включённым VPN;
   - ASN не трогайте: правил по ASN в конфигах нет.
8. **Автообновление.** Настройки → «Подписка» → автообновление → вкл.
9. **Сцены.** Главная → «Глобальная маршрутизация» → «Сцена» → **«+»**:
   - **Wi‑Fi** (ваши сети) → конфиг `Rocket-WiFi.conf`;
   - **Сотовая** → конфиг `Rocket-Cellular.conf`.

   Затем на главном экране выберите режим **«Сцена»** и включите VPN.

## Проверка

- Дома: заблокированное открывается, в журнале запросов оно идёт через **VPN [Германия Hysteria / Vless]**; Apple и российское — **DIRECT**.
- На улице: Instagram, Telegram и YouTube открываются; в `Rocket-Cellular.conf` в группе **VPN** 10 узлов, группа **RU** показывает RU-SILVER (Cooper и VPN — запасные).
- Пуши приходят. Госуслуги и банк работают.
- Claude на сотовой заблокирован. Так задумано: он работает только через свой сервер дома.

## Если не работает

| Что | Что делать |
|---|---|
| «Подключено», но ничего не грузится | У узла: TLS → Fingerprint → **Chrome 140** (для XHTTP — **Firefox 148**). Обновите Shadowrocket |
| Подписка не обновляется | Выключите VPN → обновите → включите |
| На улице все узлы с таймаутом | Сеть в этом месте режет всё. Подождите или смените место |
| Дома заблокированное не открывается | Лежат оба протокола или IP сервера заблокирован ТСПУ — смените IP/сервер (на будущее — каскад через RU‑VPS). Либо узлы переименованы и группа VPN пуста |
| На улице группа пустая | Провайдер переименовал узлы или добавил тариф — допишите в регулярку `[Gold\|Platinum\|…]` |
| Что-то от Apple не работает дома (Apple Intelligence, Siri) | Уберите блок «Apple — напрямую» из Wi‑Fi‑конфига |
| Российское (Avito, ВК) уходит через зарубежный узел или не открывается | Не загрузились списки: Конфиг → правила → все `RULE-SET` должны быть с ✅. Списки берутся с `cdn.jsdelivr.net`; если не грузятся — включите VPN, обновите вручную |
| Группа VPN метается между узлами или держится на мёртвом | Проверьте, что Easy Mode выключен: Главная → Глобальная маршрутизация → Группа. Опросы узлов: Wi‑Fi и сотовая VPN — раз в 120 с, допуск 500 / 1500 мс; группа RU — раз в 120 с |
| Не приходят пуши | Проверьте шаг 5 |
| На улице не работает Apple (App Store, iCloud, пуши) | Apple на сотовой идёт через группу **RU**; если Silver и Cooper лежат, она сама уходит в VPN. Посмотрите, какой узел показывает RU, и подождите до 2 минут |
| Проверка IP (2ip, ifconfig.me) дома показывает российский адрес | Так задумано: эти сервисы идут напрямую ради российских приложений. VPN проверяйте через ipleak.net или журнал запросов |

## Важно

- Последнюю строку конфигов `FINAL,VPN` **не менять**: через неё идёт всё заблокированное.
- **Узлы найдены по именам.** Переименовали свой сервер или провайдер сменил названия → поправьте `policy-regex-filter` в группах.
- **Xray на своём сервере держать на стабильной версии** (сейчас 26.3.27): предрелизы 26.9.x ломают REALITY в Shadowrocket. 3x‑ui обновляет ядро вместе с панелью.
- Ссылки подписок и ключи — пароли. В этот репозиторий их **не класть**.

## Изменения 2026-10-19

- Списки правил (`RULE-SET`) переведены с `raw.githubusercontent.com` на зеркало `cdn.jsdelivr.net`: GitHub у части операторов блокируется, и списки не загружались. `update-url` и ссылки на конфиги тоже переведены на jsDelivr.
- Wi‑Fi: `tabakovo.ru`, `appstorrent.ru` и IP серверов `45.12.62.45`, `167.233.47.62`, `77.42.13.177` идут через VPN (с российских IP до серверов Hetzner нет доступа). Эти правила стоят выше блока торрентов (он ниже российского DIRECT-списка).
- Wi‑Fi: сервисы проверки IP (`ipify.org`, `ifconfig.me`, `eu.2gis.com`, `ping.ozon.kz` и др.) — напрямую, чтобы российские приложения не видели немецкий адрес и не жаловались на VPN.
- Сотовая: `tabakovo.ru`, `appstorrent.ru` и IP своих серверов — через VPN, как на Wi‑Fi (иначе `.ru` уходил в RU, а с российских IP до Hetzner нет доступа). Сервисы проверки IP — через RU.
- Avito: на Wi‑Fi всё напрямую. На сотовой `avito.ru`/`avito.st` напрямую (они в белом списке), `avito.com` — через RU (его в белом списке нет).
- Опрос узлов раз в 120 с (Wi‑Fi и сотовая VPN), допуск 500 / 1500 мс; RU идёт Silver → Cooper → VPN.
- Реклама на Wi‑Fi: вместо списка ключевых слов (ложно блокировал Wix и analytics.google.com) — облегчённый список доменов AdvertisingLite.
- Торренты на Wi‑Fi блокируются ниже российского DIRECT-списка; sentry.io на сотовой больше не блокируется.
- QUIC (UDP 443): на Wi‑Fi блокируется только для трафика, дошедшего до `FINAL`; на сотовой — для всего (при белых списках UDP режут, и без блока приложения ждут таймаут).
